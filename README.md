# LibEscape

## About
- A 2d platformer game where you have to climb the stairs and walk through the platforms to reach the green flag and win

- You can use the arrow keys to to move the character

- Up and Down keys will only work if you are standing in front of a ladder and are used to climb or get down from the ladder 

- Once you reach the green flag you will win the game 

- But beware if you fall into the pitch where there are no platforms you will lose thhe game

## Resources

- All the tiles,sprites and music are generated by AI chatbots or are downloaded from the some other sources on web

## Important

- This game can only be played on pc for now

- This game contains background sound and other sounds(like walking and climbing) so I recommend turning down you rvolume before playing the game
